## About care tools

care tools is a browser-based web app for keeping key care management information organized in one place. It focuses on the practical details that often need to be checked quickly, such as resident master data, weight history, support schedules, and family relationship references.

The project is suited to teams or individuals who want a lightweight way to structure daily care-related work without switching between separate notes or records. By keeping these items together in a web interface, it can support simpler review, faster lookup, and more consistent routine handling.
